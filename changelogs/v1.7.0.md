### 🛡️ Improvements
- Added a new startup screen and refreshed app icon
- Future app updates will now install quietly without opening an installation window
- Added Fill and Free crop modes, zoom controls, and drag-to-position for cover images
- Improved dialogs so they fit and scroll better on smaller windows
- Redesigned the Add Game and Add Combo forms to be cleaner and easier to scan
- Made Character resources easier to browse and open from anywhere on each resource card
- Improved combo notation parsing for repeated buttons and repeat groups with optional spacing
- Combo descriptions now support multiple lines and Markdown formatting
- Added a native `.deb` installer for Debian-based Linux distributions
