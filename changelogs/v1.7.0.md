### 🛡️ Improvements
- Redesigned splash screen and app icon
- Future in-app updates (not portable) will install silently after restart
- Added Fill/Free crop modes and drag-to-position options to cover images
- Improved dialogs so they fit and scroll better on smaller windows
- Redesigned the Add Game and Add Combo forms to be cleaner and easier to digest
- Made Character resources easier to browse and open on character resource card
- Combo descriptions now support multiple lines and Markdown formatting
- Added a native `.deb` installer for Debian-based Linux distributions
- Seperate and expanded parsing for Standard/Numpad, NRS, and Tekken-style notations. Games that used the previous `NRS/Tekken` input option will be set to Tekken input; NRS-style games can select the new `NRS` input option from the Add or Edit Game screen.
- Redesigned and expanded the Notation Guide with complete input style specific references (Now includes realistic examples and live text and icon previews)
